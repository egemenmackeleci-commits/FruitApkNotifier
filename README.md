# FruitWatch 🍎

Blox Fruits stock & value tracker for Android.

## Features

- Normal Stock
- Mirage Stock
- Fruit Values
- Value alerts
- Favorites
- AMOLED UI
- Notifications
- Background stock checking
- Custom fruit images

## Data Source

Stock and value data is retrieved from Blox Fruits Values.

FruitWatch is not affiliated with, endorsed by, or sponsored by Blox Fruits,
Roblox, or Blox Fruits Values.
